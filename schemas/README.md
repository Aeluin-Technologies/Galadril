# Galadril schemas 📜

> *"He that breaks a thing to find out what it is has left the path of wisdom."*

Schemas are the tools that enable Galadril's various systems to understand each
other. Data passes through a broker according to specific schemas.

* **Avro schemas** are used by message broker to share heterogenous metadata and
    permissions.
* **PostgreSQL migrations** are used to prepare database and its tables.
* **SpiceDB contract** is used to orchestrate fine-grained permissions.
