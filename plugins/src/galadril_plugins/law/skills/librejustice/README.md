# Méthodes LibreJustice adaptées à Galadril

Méthodes et références adaptées du plugin [LibreJustice](https://github.com/librejustice/librejustice/tree/c4c6514cee021b809d6e505c79bbc7aeb72863ef/plugins/librejustice), sous licence Apache-2.0. Voir [la licence](LICENSE.md). Les instructions de connexion sont propres à Galadril. Les deux méthodes conservent les procédures de recherche de la révision citée et ajoutent les exigences de confidentialité et de validation officielle de Galadril.
