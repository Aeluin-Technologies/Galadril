# Galadril ML 🤖

Galadril is AI-driven: its pipelines rely heavily on it. As such, we have
created several libraries that handle various useful components:

| Component | Purpose |
| :--- | :--- |
| **Eru** | Multi-step triplet extractor for structured text processing |
| **Galadril Inference** | Manages base modal and pre-integrated ones |
| **Scribe** | RAG-enabled chatbot integrated with tenant-specific data |
