# Scoped instruction through generic task graphs

Scribe owns a domain-neutral durable task graph. Installed workflow toolsets
declare allowed skills, common instructions, role instructions, research tools
and replay guarantees. Plugin arguments cannot import code or supply service
URLs. Legal decomposition and procedural rules belong entirely to `law`.

`law` first decomposes the original memorandum into grounds with exact passages,
questions, legal causes, branches, exhibit indices and acyclic dependencies. It
rejects passages absent from the supplied original text and indices outside the
authorized attachment scope. Independent grounds run in parallel; each ground
receives separate norms, case-law, evidence and objections examinations. A
justified discovery can refine the question or request another already authorized
exhibit. Requests outside that scope fail closed.

Task ordering (`depends_on`) does not grant read access. Only explicit artifact
inputs (`input_ids`) enter a task conversation. Large artifacts have exact
paginated reads; they are not silently replaced by summaries. Each child receives
a fresh dependency context without chat history, project instructions, memory,
mailbox, sandbox or sibling reports. Registered research tools retain mediated
Gateway authorization, including when the selected plugin requires confidentiality.

The coordinator composes a draft from the research reports. Three separate
defenders receive only this released draft and explicitly shared exhibits. They
independently examine procedure, proof/citations and contrary case law. The
coordinator revises the draft; a separate final task checks references, temporal
versions, exhibits, conclusions and the inventory. Human validation remains
mandatory. The registered `recoursadmin` template and encrypted document profile
injection retain their existing boundaries.

All workers, including the coordinator, receive `raisonnement.md`. Drafting
instructions remain in `redaction.md`; incidence-of-defects instructions are a
single plugin-owned resource shared by the relevant roles. Danthony, El Bahi and
Hallal remain distinct mechanisms. Structural checks reject category mismatches
but cannot establish the truth of factual or legal premises.

Each immutable task scope is checkpointed before execution and after completion
or interruption. Completed tasks are restored without repeating model calls;
changed scopes require a new revision. Consumption after the last coordinator
checkpoint is reconciled during replay. Research tasks may replay after an
interruption; this does not grant replay permission for tools with side effects.

Concurrency, graph size, model requests, tokens, cost and overall duration remain
bounded. Before starting concurrent work, the graph reserves capacity and retains
a coordinator reserve. Tool calls have no numerical quota. A failed batch cancels
and joins its sibling tasks so their checkpoints and consumption are recorded.
The static team roster remains for compatibility; it is not the dynamic task
count. Report identities use the existing authorized report reader in Pengolo.
